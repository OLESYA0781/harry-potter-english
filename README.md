# Harry Potter’s English Adventure

Интерактивный индивидуальный пробный урок английского для ребёнка A1–A2 (40–45 минут). React 19, TypeScript, Vite, Tailwind CSS. Без регистрации, ключей API и платных интеграций.

## Запуск

Требуется Node.js 22 или новее и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Для production-сборки:

```sh
npm run build
npm run preview
```

## Как провести урок

1. Нажмите **Start our adventure!**. Используйте Back, Next или меню глав.
2. Ребёнок отвечает устно преподавателю, выбирает картинки и выполняет задания. Перетаскивание работает мышью и сенсорным указателем. Альтернатива: нажать карточку, затем место назначения. В заданиях на порядок нажимайте карточки и используйте стрелки ← →; нажатие выбранной карточки возвращает её в набор. Все кнопки доступны с клавиатуры.
3. **Teacher mode** открывает русские методические заметки, ответы, текст аудирования и ручные оценки. Это переключатель для совместного урока, не защищённый паролем доступ. Не показывайте ответы до первой попытки.
4. Оцените семь вопросов Speaking, чтение вслух и финальный рассказ: independently = 2, with help = 1, couldn't answer = 0. Оценка знакомства дополнительная и в расчёт уровня не входит.
5. В последней главе скачайте сертификат. В режиме преподавателя доступны диагностика и **Download results (PDF)**. Имя, включая кириллицу, отображается в PDF. PDF формируется на устройстве; сам PDF не отправляется на сервер.

### Диагностика

Автоматические показатели: 3 задания Vocabulary, 8 Grammar (включая There is/are), 10 Reading comprehension, 5 Listening, 11 Sentence building (6 сопоставлений и 5 предложений). Устная речь — 8 ручных оценок, чтение — 1. Для уровня нужны все задания и все обязательные ручные оценки.

Первый проверенный ответ используется для диагностики. Повторная правильная попытка приносит звезду, но не изменяет первый результат. Максимум — 37 звёзд. Уровни: A2 — среднее по семи навыкам не менее 80% и каждый навык не менее 65%; A1+ — среднее не менее 60% и каждый навык не менее 40%; иначе A1. Это ориентир для преподавателя, **не официальный языковой тест**. Пока данных недостаточно, уровень не выставляется.

Прогресс, имя и оценки сохраняются в localStorage. При настроенном Supabase после входа они синхронизируются между устройствами одной ученицы; без конфигурации сохраняются только в этом браузере. **Restart** после подтверждения сбрасывает урок и передаёт сброс в облако. Исходная резервная копия первого переноса сохраняется. В приватном режиме или при блокировке хранилища локальное сохранение может быть недоступно.

Английское озвучивание использует Web Speech API и голоса браузера/операционной системы. Доступность и звучание зависят от устройства; при отсутствии голоса преподаватель может прочитать скрытый текст самостоятельно. Кнопка звука отключает озвучивание. Видеосвязь и распознавание речи не требуются: преподаватель слушает ребёнка лично или через привычную платформу звонков.

Все персонажи, замок, интерьер, еда, школьные предметы и выражения настроения выполнены в едином объёмном мультяшном стиле. Созданные для проекта иллюстрации хранятся локально в `public/art/*.webp`; фотографии и кадры фильмов не используются. Системные эмодзи в интерфейсе заменены иллюстрациями. Таблицы изображений отображаются через `src/Art.tsx` без дополнительных сетевых сервисов. Это неофициальный учебный проект; имена и мир принадлежат их правообладателям.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
npm run test:sql
npm run test:cloud
```

Браузерные тесты используют системный `/usr/bin/chromium` в облачной среде. Для другой машины задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`, либо установите Chromium через `npx playwright install chromium` (для стандартного скачанного браузера удалите `executablePath` из конфигурации). Тесты сами запускают Vite, если сервер ещё не запущен.

Проверяются навигация, сохранение и сброс, реальные проверки ответов, порядок слов, перетаскивание, аудирование, ручные оценки, скачивание PDF и отсутствие горизонтальной прокрутки на мобильном экране.

## Публикация через Cloudflare Pages

Рабочий сайт: https://vika-english.pages.dev. Исходный репозиторий — `OLESYA0781/harry-potter-english`, production branch — `main`. Изменения проходят через отдельную ветку и Pull Request; после объединения Cloudflare Pages автоматически собирает `main`, если интеграция GitHub активна.

Настройки сборки: корень репозитория, `npm run build`, каталог `dist`, Node.js 22. Для Supabase используются существующие переменные Cloudflare Pages `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY`. Они встраиваются Vite во время сборки. Значения переменных и рабочую базу при добавлении уроков не меняйте. Секретные ключи в браузерный код не помещаются. `netlify.toml` остался от прежней инфраструктуры; для публикации проекта он не используется.

Переходы между кабинетом и уроками используют hash-адреса: `/` открывает кабинет, `/#/lessons/trial` — пробное занятие на последнем сохранённом этапе. Серверный маршрутизатор для уроков не требуется.

## Главное меню и добавление уроков

Все прежние 15 глав, A2/B1, упражнения, иллюстрации, оценки и PDF находятся внутри **«Пробного занятия»**. При открытии главной страницы появляется кабинет с приветствием, выбором урока и прогрессом. Верхнее меню «Уроки» и ссылка «Главное меню» доступны внутри каждого урока.

Единый реестр — `src/lessons/registry.ts`; новые модули отображаются первыми по `addedAt`. Как добавить урок, определить его статус и сохранить независимость прогресса: [docs/LESSONS.md](docs/LESSONS.md).

## Find the Differences · A2–B1

Дополнительная глава перед итогами, 5–7 минут сверх основного урока. На двух картинках шесть изменений: Рон ест яблоко / пьёт воду; на столе три / две книги; мяч под / на столе; чашка чая есть / отсутствует; Гермиона сидит на полу / на диване; в A день, в B ночь с луной за окном. Нажатие на соответствующую область любой картинки отмечает находку сразу на обеих. Повторное нажатие не увеличивает счёт. Доступно управление Tab и Enter.

После находки ребёнок описывает её устно. Кнопка **I have tried!** открывает возможность показать образец. Подсказки учат сравнивать с **but**, использовать **there is/are**, предлоги места и **Present Continuous**. В режиме преподавателя видны все ответы и четыре отдельные ручные оценки. Их сводка показана в итогах и на дополнительной странице PDF. Количество находок само по себе не оценивает английский; глава не меняет основной расчёт A1–A2 и не подтверждает B1. Все ответы и отметки сохраняются. Старый прогресс автоматически переносится в новую структуру из 15 глав.


## Hermione’s Grammar Challenges · A2 и B1

Две независимые главы перед итогами: **Grammar Challenge A2** и **Grammar Challenge B1**, ровно по 10 заданий с текстовым вводом. Любой раздел доступен сразу, без прохождения другого уровня. Карточки открываются по одной. Back/Next и кнопки 1–10 переключают вопросы; введённые ответы сохраняются. Check проверяет ответ; Hint даёт подсказку без готового решения; Try Again разрешает повторную попытку. После Check доступны правильный ответ и объяснение. Пробелы, регистр и тип апострофа не влияют на проверку; принимаются did not go / didn’t go, would buy / ’d buy, who / that в соответствующих заданиях.

**A2 Grammar: X/10** и **B1 Grammar: X/10** — число верных первых попыток (включая попытки с Hint, которые отмечены отдельно). Также показаны самостоятельные первые ответы, текущие верные ответы, использованные Hint, верные ответы после Hint, число ошибочных проверок, повторных проверок, пропущенных и ещё не проверенных вопросов. Next без Check отмечает вопрос пропущенным, сохраняя черновик; Finish challenge учитывает все оставшиеся непроверенные вопросы как пропуски. Повторные попытки не меняют первый результат.

В режиме преподавателя доступны правила, история ответов, конкретные темы для повторения и дополнительная ручная оценка собственных предложений B1. Оба отчёта добавляются в общие итоги и PDF, даже если тест ещё не начат. Это отдельные показатели, не автоматическое подтверждение A2 или B1 и не замена комплексной оценки чтения, аудирования и речи. Дополнительные разделы требуют отдельного времени сверх основного урока. Прогресс прежних версий сохраняется при обновлении.


На четвёртой главе все шесть персонажей изображены вместе на одной непрозрачной иллюстрации гостиной. Нажмите на персонажа, чтобы выбрать вопрос о его действии. Кнопка Zoom in увеличивает сцену; на телефоне увеличенную картинку можно прокручивать вбок. Zoom out возвращает общий вид. Задание на сопоставление ниже сохраняется.

## Облачное сохранение Supabase

Настройка единственной учётной записи, RLS, SQL-миграция, переменные Cloudflare Pages и безопасный перенос localStorage: [docs/SUPABASE.md](docs/SUPABASE.md). Без конфигурации Supabase сохраняется локальная работа. Проверки синхронизации: `npm run test:sql` и `npm run test:cloud`.
