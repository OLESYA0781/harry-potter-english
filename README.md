# Harry Potter’s English Adventure

Интерактивный индивидуальный пробный урок английского для ребёнка A1–A2 (40–45 минут). React 19, TypeScript, Vite, Tailwind CSS. Без регистрации, ключей API и платных интеграций.

## Запуск

Требуется Node.js 22 или новее и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Для production-сборки:

```sh
npm run build
npm run preview
```

## Как провести урок

1. Нажмите **Start our adventure!**. Используйте Back, Next или меню глав.
2. Ребёнок отвечает устно преподавателю, выбирает картинки и выполняет задания. Перетаскивание работает мышью и сенсорным указателем. Альтернатива: нажать карточку, затем место назначения. В заданиях на порядок нажимайте карточки и используйте стрелки ← →; нажатие выбранной карточки возвращает её в набор. Все кнопки доступны с клавиатуры.
3. **Teacher mode** открывает русские методические заметки, ответы, текст аудирования и ручные оценки. Это переключатель для совместного урока, не защищённый паролем доступ. Не показывайте ответы до первой попытки.
4. Оцените семь вопросов Speaking, чтение вслух и финальный рассказ: independently = 2, with help = 1, couldn't answer = 0. Оценка знакомства дополнительная и в расчёт уровня не входит.
5. В последней главе скачайте сертификат. В режиме преподавателя доступны диагностика и **Download results (PDF)**. Имя, включая кириллицу, отображается в PDF. PDF формируется на устройстве; данные никуда не отправляются.

### Диагностика

Автоматические показатели: 3 задания Vocabulary, 8 Grammar (включая There is/are), 10 Reading comprehension, 5 Listening, 11 Sentence building (6 сопоставлений и 5 предложений). Устная речь — 8 ручных оценок, чтение — 1. Для уровня нужны все задания и все обязательные ручные оценки.

Первый проверенный ответ используется для диагностики. Повторная правильная попытка приносит звезду, но не изменяет первый результат. Максимум — 37 звёзд. Уровни: A2 — среднее по семи навыкам не менее 80% и каждый навык не менее 65%; A1+ — среднее не менее 60% и каждый навык не менее 40%; иначе A1. Это ориентир для преподавателя, **не официальный языковой тест**. Пока данных недостаточно, уровень не выставляется.

Прогресс, имя и оценки сохраняются в localStorage только этого браузера и устройства. **Restart** после подтверждения очищает данные урока. На общем устройстве сбрасывайте урок между учениками. В приватном режиме или при блокировке хранилища сохранение может быть недоступно.

Английское озвучивание использует Web Speech API и голоса браузера/операционной системы. Доступность и звучание зависят от устройства; при отсутствии голоса преподаватель может прочитать скрытый текст самостоятельно. Кнопка звука отключает озвучивание. Видеосвязь и распознавание речи не требуются: преподаватель слушает ребёнка лично или через привычную платформу звонков.

Все персонажи, замок, интерьер, еда, школьные предметы и выражения настроения выполнены в едином объёмном мультяшном стиле. Созданные для проекта иллюстрации хранятся локально в `public/art/*.webp`; фотографии и кадры фильмов не используются. Системные эмодзи в интерфейсе заменены иллюстрациями. Таблицы изображений отображаются через `src/Art.tsx` без дополнительных сетевых сервисов. Это неофициальный учебный проект; имена и мир принадлежат их правообладателям.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют системный `/usr/bin/chromium` в облачной среде. Для другой машины задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`, либо установите Chromium через `npx playwright install chromium` (для стандартного скачанного браузера удалите `executablePath` из конфигурации). Тесты сами запускают Vite, если сервер ещё не запущен.

Проверяются навигация, сохранение и сброс, реальные проверки ответов, порядок слов, перетаскивание, аудирование, ручные оценки, скачивание PDF и отсутствие горизонтальной прокрутки на мобильном экране.

## Публикация на Netlify

1. Сохраните файлы проекта в GitHub-репозиторий.
2. В Netlify выберите **Add new project → Import an existing project**, подключите GitHub и выберите репозиторий.
3. Настройки уже заданы в `netlify.toml`: build command — `npm run build`, publish directory — `dist`, Node.js — 22. Переменные среды и секреты не нужны.
4. Нажмите **Deploy**. После успешной сборки Netlify предоставит обычную HTTPS-ссылку. Откройте её на устройствах преподавателя и ученика.

Альтернативно: выполните `npm run build` и загрузите папку `dist` через Netlify Drop. Для обновлений потребуется новая загрузка.

**Важно:** приложение не синхронизирует ответы между разными устройствами. Для общего прохождения демонстрируйте экран урока с устройства, на котором сохраняются ответы и оценки, либо проводите урок рядом с ребёнком. Публикация сайта и создание аккаунта Netlify выполняются владельцем; приложение само ничего не публикует.


## Публикация с телефона без терминала

После появления файлов проекта в ветке `main` откройте свой проект в Netlify:

1. В **Project configuration → Build & deploy → Continuous deployment** проверьте репозиторий `OLESYA0781/harry-potter-english` и production branch `main`.
2. В настройках сборки укажите **Base directory** — пустое поле (корень репозитория), **Build command** — `npm run build`, **Publish directory** — `dist`. **Package directory** также оставьте пустым. Файл `netlify.toml` уже задаёт корень проекта, команду сборки, каталог публикации и Node.js 22.
3. Откройте **Deploys → Trigger deploy → Deploy site**. Если видна кнопка **Clear cache and deploy site**, используйте её после предыдущей неудачной сборки.
4. Дождитесь статуса **Published** и нажмите ссылку сайта в Netlify. Если автоматическая сборка уже началась после обновления GitHub, просто дождитесь её завершения.

Команды в терминале вводить не нужно. Иллюстрации включены в `public/art`, а их отображение настроено в `src/Art.tsx`; отдельная загрузка изображений не нужна.


## Find the Differences · A2–B1

Дополнительная глава перед итогами, 5–7 минут сверх основного урока. На двух картинках шесть изменений: Рон ест яблоко / пьёт воду; на столе три / две книги; мяч под / на столе; чашка чая есть / отсутствует; Гермиона сидит на полу / на диване; в A день, в B ночь с луной за окном. Нажатие на соответствующую область любой картинки отмечает находку сразу на обеих. Повторное нажатие не увеличивает счёт. Доступно управление Tab и Enter.

После находки ребёнок описывает её устно. Кнопка **I have tried!** открывает возможность показать образец. Подсказки учат сравнивать с **but**, использовать **there is/are**, предлоги места и **Present Continuous**. В режиме преподавателя видны все ответы и четыре отдельные ручные оценки. Их сводка показана в итогах и на дополнительной странице PDF. Количество находок само по себе не оценивает английский; глава не меняет основной расчёт A1–A2 и не подтверждает B1. Все ответы и отметки сохраняются. Старый прогресс автоматически переносится в новую структуру из 13 глав.
