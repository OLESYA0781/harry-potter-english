# Homework 0 — The Magic of To Be

Открывается через Homework → Homework 0 (`#/homework/0`) и ссылку в Lesson 0.
Светлое оформление, пять заданий в заданном порядке.

- Task 1: 10 предложений, **12** inline-полей.
- Task 2: 10 русских предложений; по одному текстовому полю под каждым.
- Task 3: 5 диалогов; по одному многострочному полю под каждым.
- Task 4: 6 диалогов, **13** inline-полей.
- Task 5: пять своих предложений, am/is/are, минимум 5 слов My Vocabulary,
  хотя бы одно отрицание; большое текстовое поле для пяти предложений.

По обновлённому заданию пользователя Tasks 2, 3 и 5 выполняются прямо на сайте.
Указания про тетрадь убраны. Все предложенные русские тексты сохранены,
включая Task 2 №10 «Она пишет письма друзьям после школы.» (Present Simple).
Свободные ответы не проверяются автоматически и не раскрываются.

Все ответы (25 пропусков и 16 текстовых полей) сохраняются независимо в root answers с
префиксом `@vika/lesson/lesson-0-homework/`, id задания/предложения/пропуска.
Порядок карточек не определяет ключ. Используется существующий setState,
localStorage-журнал/outbox и RPC/CAS. Нет новой схемы/миграции Supabase,
регистрации, очистки или перезаписи сохранённого Lesson 0/Trial Homework.
Без входа работает локальное автосохранение; облачная синхронизация требует
существующую авторизацию ученицы. Свободные переводы и сочинение проверяются вручную.
Нет раскрытия правильных ответов, нормализации текста, проверки или готовых
ответов в placeholder. Ввод сохраняется дословно, включая ошибки и пробелы.

Проверки: 52 unit-теста; 4 браузерных сценария Homework 0 на 390/820/1180/1440
(25 пропусков + 16 текстовых полей, reload, переходы, размеры полей, отсутствие готовых ответов/near),
регрессия меню Homework, облачный сценарий двух устройств и независимых
offline-изменений с сохранением старых записей; root/Pages production build
и Pages regression. Chromium не заменяет настоящую проверку iPhone Safari.

Task 1: swimming pool — big; pictures — on the wall; №7 — It ___ a train. It ___ a tram.; №8 — A plane ___ fast. Для новых №7/8 используются новые id train-tram и plane-fast; старые ответы bank/cafe сохраняются в журнале без подстановки в новые предложения.

Task 4: Ron happy? — Yes, he ___; последний диалог — ___ Ron a teacher? — No, he ___. Для замены friends используется новый id ron-teacher, исторические ответы friends не меняются.

Текстовые поля имеют ключи written/translations/<stable-id>, written/dialogues/<stable-id> и written/profile/hogwarts в прежнем namespace Homework 0. Семантические id закреплены рядом с текстом; порядок отображения не определяет ключ. Переводы (включая пробелы/переносы) синхронизируются независимо от пропусков, фото и других уроков.
