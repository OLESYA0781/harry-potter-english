# Mystery House artwork

New original generated illustrations matching the existing Trial Lesson `../common-room.webp` style reference: warm cinematic 3D storybook rendering, honey stone, emerald roof, brass lanterns and friendly expressive people. No external image dependencies.

- `mystery-house.webp`: square front-on house with six empty arches. HTML/CSS doors overlay the image using percentage coordinates; artwork never crops or changes the hit areas. Upper arches are shorter because of the balcony. No exercises or text are baked into the image.
- `mystery-jobs.webp`: 4×2 equal square atlas. Top row: pilot, doctor, farmer, teacher. Bottom row: artist, singer, female chef, shop assistant. The eight familiar professions are displayed without labels in listening rounds. The female chef visibly cooks food; the doctor has a white coat and hospital background.

Original PNGs were encoded to WebP without repainting. Existing Trial portraits and Lesson 1 transparent Ron/Hermione cutouts are reused unchanged. The tired Ron cell is 0; Hermione is cell 2, placed against authored library shelves.
