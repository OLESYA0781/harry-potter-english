# Golden Key quest artwork

Original generated cinematic 3D storybook illustrations, using the existing Trial Lesson `../../common-room.webp` as the direct style reference. Honey stone, emerald, burgundy, golden lanterns and friendly expressive faces. No external asset URLs.

- `buildings.webp`: exact 3×2 square atlas. Top: hospital, restaurant, museum. Bottom: bank, theatre, school. Each complete building cell is rendered as a separate interactive object. The city is not one flat map image with decorative hotspots.
- `office-worker.webp`: bank office worker writing at a wooden desk. Other specific story characters reuse the existing Mystery House job atlas: doctor 1, chef 6, artist 4, singer 5, teacher 3.
- `guardian.webp`: clean secret-room background with empty pedestal. Generated as an edit of the initial guardian scene, removing only the wizard so he can animate independently.
- `wizard.webp`: matching isolated transparent guardian, emerald robe and gold staff; animated foreground that moves aside at the end.
- `key.webp`: isolated transparent ornate 3D golden key with emerald gem. This independent inventory object glows, rises and travels to Hermione.

Original PNGs remain in the generation directory. WebP encoding retains alpha for wizard/key. Final animation uses CSS transforms/position and honors reduced motion; no flashes or autoplay audio.
