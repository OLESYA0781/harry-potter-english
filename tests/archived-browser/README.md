# Исторические проверки

`grammar-before-removal.spec.ts` сохраняет прежние браузерные тесты отдельных глав A2/B1 и старой итоговой страницы. Эти главы 13–15 убраны из учебной навигации по просьбе пользователя. Файл хранится для истории и не входит в текущий `testDir` Playwright (`tests/browser`).

Текущие проверки совместимости старых данных и новой навигации находятся в `tests/browser/grammar.spec.ts`. Модульные тесты грамматики продолжают выполняться: её данные/алгоритмы нужны для исторических отчётов. Экспорт PDF удалён по более позднему запросу пользователя. Текущие результаты основной диагностики проверяются через отдельную кнопку Results в преподавательском режиме.
